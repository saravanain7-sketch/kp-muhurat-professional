# GuruAgasthiya Web 12.3

Standalone web/PWA package built from the uploaded GuruAgasthiya 12.3 APK `assets/index.html` and its bundled `names.txt`. No KP Muhurat code or integration is included.

## Deploy
Upload every file in this folder to the same directory on your static web host (for example, the repository root on GitHub Pages). Open the site over HTTPS and use the browser's Add to Home Screen / Install option.

## Source preservation
The application HTML and bundled names data are taken from the supplied APK. Only the web-app manifest link and service-worker registration are added to the HTML to support PWA installation and caching.
